# Hartielectrocool Climatización — web

Web de una sola página para Harti Electrocool Climatización (Av. de la Constitución, 67, 13620 Pedro Muñoz, Ciudad Real).

## Cambiar los datos

Teléfono, WhatsApp, email, dirección, redes y horario están en un solo sitio:
el bloque `const EMPRESA = { ... }` al final de `index.html`.

## Presupuestos

El formulario no necesita servidor: al pulsar "Enviar por WhatsApp" abre WhatsApp con el mensaje ya escrito para el número de `EMPRESA.whatsapp`.

## Publicar

GitHub Pages: Settings → Pages → Branch `main`, carpeta `/ (root)`.

## Diseño

- `DESIGN.md` y `.impeccable/design.json`: sistema de diseño (vista de cámara térmica, Unbounded + Manrope + JetBrains Mono).
- `PRODUCT.md`: qué es la web y para quién.
